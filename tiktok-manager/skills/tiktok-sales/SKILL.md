# TikTok Sales

## CTA kitabxanası (məqsədə görə)
- Engagement: "Sən hansını seçərdin? Şərhdə yaz."
- Follow: "Davamı üçün izlə."
- Lead/DM: "DM-də '<açar söz>' yaz, ətraflı göndərim."
- Traffic: "Link profildədir."
- Sale: "Sifariş üçün DM / link" — yalnız əlaqə kanalı `business.json`-dadırsa.

## Təklif
Təklif = məhsul + fayda + (real) qiymət/şərt + aydın addım. Hər element `business.json`-dan; yoxdursa marker və sahibə bir sual.

## Lead → satış
HOT: 1 cavabda sifariş addımı. WARM: sual cavabı → dəyər → dəvət. COLD: satış yoxdur.

## Ölçmə
Satış nəticələri yalnız sahibin bildirdiyi real rəqəmlərdir; `results.json`-a mənbə ilə yazılır. Uydurma konversiya yoxdur.
